# 🎵 BeatBox Music Player

A custom-designed Android music player app with smooth UI, animations, and core features like play, pause, next, previous, and song info.

## ✨ Features

- 🎧 Play, pause, next, previous song controls
- 🎨 Clean and modern UI with smooth transitions
- 🖼️ Album cover and artist info display
- 📂 Local audio file access
- 🎛️ Seekbar and playback timer
- 🌓 Dark theme support
